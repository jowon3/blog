# BLOG STUDIO 네이버 입력 검토 및 로컬 구조

검토일: 2026-10-23. 현재 실행 모드: **수동 입력 전용**.

## 정책 결정

- 네이버 이용약관: https://policy.naver.com/policy/service.html
- 네이버 게시물 운영정책: https://policy.naver.com/policy/service_group.html
- 현재 공식 API 목록: https://developers.naver.com/products/intro/plan/plan.md

이용약관은 네이버의 사전 동의 없이 자동화된 수단으로 서비스 영역에 콘텐츠를 삽입하는 행위를 금지합니다. 공식 API 목록에서도 일반 블로그 글쓰기 자동 입력 API는 확인되지 않습니다. 현재 프로젝트에 별도 허락을 입증할 자료가 없으므로, Playwright를 설치하거나 네이버 에디터의 DOM을 자동 조작하는 코드는 제공하지 않습니다. Playwright 설치 여부와 관계없이 자동 입력은 차단됩니다. 단순 설정 변경으로 이를 해제할 수 없습니다.

네이버 로그인, 보안 인증, 에디터 입력, 사진 업로드, 발행 버튼 클릭은 사용자 직접 작업입니다. 실제 네이버 계정의 로그인·입력·발행 테스트는 수행하지 않습니다. 글쓰기 링크가 네이버 로그인 또는 기존 에디터 화면으로 연결되면 사용자가 계정과 블로그를 확인합니다.

## 구조

- 기존 Next.js 웹앱: 고객별 네이버 주소, 원고·사진 확인, 개별 복사, 글쓰기 화면 열기, 사진 원본 사본 다운로드.
- 별도 선택형 로컬 진단 서버: `scripts/local-automation.cjs`. `npm run automation:local`로 127.0.0.1:4318에만 바인딩합니다. 로그인 정보·사진·원고를 전달받거나 저장하지 않습니다.
- Next.js의 `/api/local-automation`은 로컬 실행일 때만 진단 서버 상태를 조회합니다. Vercel과 비로컬 호스트에서는 로컬 요청을 보내지 않습니다.
- `GET /status`: Playwright 모듈 설치 여부, 브라우저 미실행, 작업 없음, 수동 입력 모드.
- `POST /start`: 정책상 403으로 거부합니다. 브라우저를 실행하거나 네이버로 데이터를 보내지 않습니다.
- `POST /stop`: 중단할 자동 작업이 없음을 반환합니다. 진단 서버 자체를 종료하는 API는 아닙니다.
- 루프백 주소·Host·Origin 검사를 적용합니다. 원격 웹사이트는 진단 서버를 제어할 수 없습니다.

## 수동 입력 순서

1. 고객 관리에서 네이버 블로그 주소를 저장합니다. `https://blog.naver.com/아이디`와 모바일 블로그 주소만 정규화해 허용합니다.
2. 원고를 확정하고 필요한 사진을 선택합니다. 사진 배치 탭에서 위치 제안을 확인합니다.
3. ‘네이버 블로그로 옮기기’를 누르고 고객·주소·원고·사진 순서를 확인합니다.
4. 확인 체크 후 글쓰기 화면을 열고 제목·본문·해시태그를 각각 복사해 직접 붙여넣습니다. 사진은 표시된 원본 선택 순서와 삽입 위치에 따라 직접 추가합니다.
5. 로그인과 최종 발행은 사용자가 직접 진행합니다.

한 전송 화면에서 글쓰기 열기 버튼을 반복 실행하지 못하도록 막습니다. 수동 복사·붙여넣기는 외부 에디터를 읽지 않으므로 네이버의 기존 본문에 대한 중복 여부를 자동 판별하지 않습니다. 붙여넣기 전에 사용자가 기존 입력 내용을 확인해야 합니다. 원고·고객·사진이 바뀌면 최종 확인 상태가 해제됩니다.

사진 순서/파일 원본은 변경하지 않습니다. 위치 추천은 현재 사진 목록과 일치할 때만 표시하며, 선택이 바뀌면 위치 미확인으로 표시합니다. ‘원본 사본 저장’은 브라우저에서 이미 선택한 File의 바이트를 그대로 다운로드합니다. 서버 종료 후에도 기존 브라우저 저장 데이터는 유지됩니다.

## 복구·검증

연결 실패, Playwright 미설치, 팝업 차단 시 자동 재시도나 자동 입력은 하지 않습니다. 수동 복사와 직접 열기 링크를 사용합니다. 로컬 진단이 필요하면 위 명령으로 서버를 재시작합니다. 서버 종료 또는 브라우저 창 닫기와 관계없이 원고를 자동 삭제하지 않습니다.

`npm test`: 기존 저장·AI·사진·해시태그 테스트, 네이버 주소 검증, 사진 순서와 위치 일치, 자동 실행 차단, 외부 Origin 거부, Vercel에서 로컬 요청 미발생 검증.
